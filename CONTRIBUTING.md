# Contributing

## Setup

```bash
curl -fsSL https://bend-lang.com/install.sh | sh
git clone https://github.com/onblueroses/claude-code-wrapped
cd claude-code-wrapped
scripts/test.sh
```

You need Bend, clang 14 or newer, Python 3.9 or newer (the oracle and the tests use only the
standard library), and Lean 4.34.0 through elan, which `bend PROOF.bend --verdict` uses to
recheck the proofs:

```bash
curl -sSfL https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh -s -- -y --default-toolchain leanprover/lean4:v4.34.0
```

## The rules of the repository

- `docs/semantics.md` is the specification. A change in what a metric means starts there,
  then `oracle/oracle.py`, then the Bend engine, and comes with a case in
  `tests/make_fixtures.py` that the old rule would fail.
- `bend/LAWS.bend` holds the claims; `bend/PROOF.bend` proves them. `scripts/test.sh` fails
  unless `bend PROOF.bend --verdict` prints `ALL PROOFS CHECK`.
- `bend/gen/` is generated by `bend/gen.py` from `pricing/prices.tsv`, the stylesheets in
  `bend/assets/` and the line record declared in `gen.py`; do not edit it by hand.
- `scripts/test.sh` runs every check: the proof verdict, `tests/compare.py` (metrics against
  the oracle), `tests/views.py` (every figure each format shows, formatted independently from
  the oracle's metrics, plus escaping and `--share`), and `tests/cli.py` (options and errors).
  A change to what a format shows changes `tests/views.py` with it.
- Prices change: update `pricing/prices.tsv` from the pricing page, keep a dated copy of the
  page beside it, and regenerate.

## The modules

- `main.bend`: the command line, the file walk and the shard processes.
- `lex.bend`, `fold.bend`, `ser.bend`, `par.bend`: reading transcripts into a fold, in parallel.
- `report.bend`, `bill.bend`, `out.bend`: time zones, prices, the aggregate and the JSON.
- `view.bend`: the View every format for people renders, with formatting and safe text.
- `text.bend`, `html.bend`, `card.bend`, `render.bend`: the formats and their dispatch.

## Writing Bend here

Bend checks a def against the defs above it, requires match scrutinees in parameter order,
and counts every use of a variable. Two helpers keep the modules tidy:

- `python3 bend/order.py FILE` moves each def below the defs it calls;
- `python3 bend/quant.py FILE` marks a variable `+` exactly when some path uses it twice.

Mutually recursive defs, and anything that is not structurally terminating, are `@unsafe`.
Keep code the laws talk about (`fold.bend`, `bill.bend`) free of `@unsafe` and effects, or the
proof gate cannot pass.
