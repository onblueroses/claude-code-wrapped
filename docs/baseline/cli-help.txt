Generate a Claude Code wrapped report from local JSONL history.

Usage: ccwrapped [OPTIONS] [YEAR]

Arguments:
  [YEAR]  

Options:
      --html      write claude-code-wrapped.html
      --markdown  write claude-code-wrapped.md
      --card      write claude-code-wrapped-card.html
      --archive   write per-project prompt files to ./wrapped-archive/
      --all       write all output formats (html + card + markdown)
      --open      open output in browser after writing
      --json      print JSON to stdout only, no files written
      --plain     disable colors (also respects NO_COLOR env var)
  -h, --help      Print help
  -V, --version   Print version
